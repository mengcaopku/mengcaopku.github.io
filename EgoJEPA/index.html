EgoJEPA: Beyond Retargeting for Dexterous Manipulation from Egocentric Videos

arXiv GitHub

EgoJEPA transfers manipulation skills from egocentric human videos to robots without rule-based retargeting. It learns effect-aware latent actions from 20,000 hours of human video, models the world in terms of those latent actions, and adapts to each robot through lightweight action adapters.

#How it works

Stages 1–2 learn from human video only and are shared by every robot. Only Stage 3 uses robot data.

Stage 1Human video

Human-action pre-training

Predicts how the scene changes from hand motion, learning effect-aware latent actions.

Stage 2Human video

Latent-action world modeling

Jointly predicts future video and latent actions with flow matching.

Stage 3Robot data

Embodiment-specific tuning

Lightweight adapters map each robot's actions to the shared latent action space.
