# TiCO Website

Static project page for **Thinking with Images without Coordinates**.

## Files

- `index.html`: the project page.
- `assets/css/style.css`: page styling adapted to the provided reference style.
- `assets/js/main.js`: figure lightbox and small UI helpers.
- `assets/img/*.jpg`: figures exported from the TiCO paper.
- `assets/TiCO-paper.pdf`: compiled paper PDF.
- `assets/TiCO-arxiv-source.zip`: arXiv source package kept in the bundle for local use.

The arXiv and GitHub links are placeholders until public URLs are available.
